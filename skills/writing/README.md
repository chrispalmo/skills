# Writing skills

Skills for reviewing prose and producing clean, paste-ready text.

## Skills

| Skill | Purpose | When |
| ----- | ------- | ---- |
| [proofread](proofread/SKILL.md) | Review prose in mechanical and optional substance passes | Articles, documentation, pages, and product copy |
| [plaintext](plaintext/SKILL.md) | Reply with one copyable plaintext codeblock | Prompts, emails, or other text to paste elsewhere |

## Core pattern

`proofread` uses short-lived, numbered Markdown ledgers:

1. `PROOFREAD.md` captures mechanical issues and separates `obvious` fixes from
   `unclear` editorial choices.
2. `SUBSTANCE.md`, when requested, records outdated, incorrect, broken, or
   disagreeable material for explicit user decisions.

The source remains unchanged by substance review until decisions are supplied.
