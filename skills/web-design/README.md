# Web design skills

Skills for making and validating visual interface decisions in running products.

## Skills

| Skill                               | Purpose                                        | When                                       |
| ----------------------------------- | ---------------------------------------------- | ------------------------------------------ |
| [design-tool](design-tool/SKILL.md) | Build a temporary live design construction set | Comparing or tuning visual UI alternatives |

## Core pattern

`design-tool` turns the visual decisions under review into a compact,
development-only control panel. The user manipulates the running interface,
chooses a winner, and the agent bakes that choice into production source before
removing the panel and discarded alternatives.

The approach is inspired by Chris Espinosa’s
[Calculator Construction Set](https://folklore.org/Calculator_Construction_Set.html):
parameterize subjective visual decisions so the decision-maker can evaluate
them directly.
